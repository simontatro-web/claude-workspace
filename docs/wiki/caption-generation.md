> Summary: Caption .txt file generation workflow for clipped videos in the David Scheuer paid clipping campaign; read when generating or reviewing captions

- Captions are for a paid clipping campaign, Instagram only, in Spanish
- Content is tied to David Scheuer / @academiaamz
- A caption .txt file is needed for each video
- Caption template: one-line hook specific to the clip's topic (pulled from transcript if available), followed by "🎙️ David Scheuer | @academiaamz" and "👉 Link en bio para el podcast completo", then hashtags #DavidScheuer #AmazonFBA #Ecommerce
- Rules: caption must be in Spanish; must tag @academiaamz; must include #DavidScheuer; must include a CTA referencing the link in bio for the full podcast; must make clear this is David Scheuer's content; hook line must be under 15 words and specific to that clip, not generic
